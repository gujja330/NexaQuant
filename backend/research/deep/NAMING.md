# Deep Research File Naming Convention

Per CEO 2026-09-03 · semantic prefix per research category.

| Prefix | Meaning     | Domain numbers |
|--------|-------------|----------------|
| **F**  | Fundamentals | F01-F05  (business quality, balance sheet, accounting quality, valuation, growth) |
| **S**  | Sector / Industry | F06-F08  (industry cycle, sector events, company events) |
| **T**  | Technicals  | T09  (deep technical) |
| **M**  | Macro / Regime | M10-M13  (macro, geopolitics, regime, cross-market) |
| **R**  | Risk        | R14  (risk extension) |
| **P**  | Portfolio   | P15  (portfolio construction) |
| **E**  | Execution   | E16-E17 (execution, order flow) |
| **A**  | Alt-data    | A18  (alternative data) |
| **X**  | Cross-signal | X19  (composite / cross-signal research) |
| **N**  | Narrative / News | N20 (narrative, news signals) |

**Rule** · new domain files MUST use the semantic prefix + zero-padded number.
Legacy `dNN_*.py` files are being renamed as they are touched.
